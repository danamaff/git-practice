Git — распределённая система управления версиями.
Она хранит историю изменений файлов проекта: что изменено, кем и когда.
Основные команды:
  git init    — создать локальный репозиторий
  git add     — добавить изменённые файлы в индекс
  git commit  — сохранить снимок проекта в истории
  git push    — отправить коммиты на GitHub
  git pull    — получить изменения с GitHub
  git branch  — работать с ветками
  git merge   — объединить ветки
